# קבלת מוצר Web/PWA — שני טלפונים

מטרת הבדיקה: קבלת מוצר הנאמנות בלבד. GAME-01/02 הם Post-launch. אין לבצע חיוב אמיתי, לשנות DNS או לפרסם Production.

לפני התחלה: לרשום כתובת QA, SHA, סוג מכשיר ודפדפן. להשתמש בחשבון בדיקה מורשה וב־SUMIT TEST בלבד; לא לאפס או לשנות משתמש קיים לצורך הדמיית הרשמה.

| בדיקה | פעולה ותוצאה נדרשת |
|---|---|
| זהות | לקוח חדש נרשם; לקוח קיים מתחבר ומקבל את הארנק המקורי ללא כפילות |
| עסק ותשלום | בעלים חדש בוחר מסלול, מאשר תנאים ומשלם בסביבת TEST. עסק נשאר לא פעיל עד אימות שרת; חזרה/רענון אינם מחייבים שוב |
| כשל תשלום | ביטול וכשל משאירים טיוטה נגישה ואינם מפרסמים כרטיסייה; ניסיון חוזר משלים אותה עסקה לפי מצב השרת |
| פרסום והצטרפות | בעלים משלים עסק וכרטיסייה; לקוח בטלפון השני מצטרף ומקבל אותה בארנק |
| QR | עובד מורשה סורק QR מהטלפון השני, מאשר ניקוב ורואה תוצאה אחת גם ברענון/סריקה חוזרת |
| מימוש וביטול | מגיעים לזכאות, מממשים פעם אחת ובודקים ביטול מורשה; היסטוריה ומספר חותמות תואמים בשני הטלפונים |
| רשת חלשה | מנתקים רשת סביב פעולה; תוצאה לא ודאית נבדקת מול השרת לפני ניסיון נוסף, ללא כפל |
| צוות | הזמנה לחשבון בדיקה; בעלים/מנהל/עובד רואים רק פעולות מורשות, כולל בניסיון להגיע ישירות לכתובת מוגנת |
| לקוחות וקמפיין | חיפוש ופתיחת לקוח, מעבר לקמפיין החזרה; טיוטה אינה שולחת. קהל, הסכמות ומכסה נבדקים לפני הפעלה מורשית |
| גילוי | חיפוש לפי שם/עיר ללא GPS, סינון שותפים, פרטי עסק והצטרפות. חיפוש בקרבתי רק אחרי הסבר ולחיצה |
| הרשאות | בחירת סוג משתמש, אישור חלקי/סירוב, מעבר עמוד וחזרה. לקוח אינו מתבקש למצלמה; מצלמת עסק נסגרת לאחר בדיקת הגישה |
| PWA ו־Push | התקנה ופתיחה מהסמל, אישור הרשאה וחיבור לחשבון, קבלת התראה בפועל; יציאה/החלפת חשבון אינם מציגים הודעות של החשבון הקודם |
| אתר ומנוי | מחיר/מסלול/מכסות ותנאים תואמים; תמיכה, בקשת החזר וביטול מנוי נגישים; מסמך TEST ותיעוד הספק נבדקים |

יש לתעד לכל שורה: עבר/נכשל/טרם נבדק, זמן, גרסה וראיה. בדיקות mocks ו־CI אינן מחליפות בדיקות אלה. פעולה כספית אמיתית או הפעלת קמפיין דורשת אישור נפרד. אדמין שירות/מכירות, חידוש/התאמת חיוב, ניטור/שחזור/rollback ואבטחה נבדקים בנפרד לפני אישור Release Candidate.
